# Security Policy

## Supported versions

Radar IA **1.0** (branche `main`) est la version actuellement maintenue.

## Reporting a vulnerability

Ne pas ouvrir d’issue publique pour une vulnérabilité.

Utiliser **GitHub Private Vulnerability Reporting** sur ce dépôt (onglet Security → Advisories → Report a vulnerability).

La documentation technique de sécurité (SSRF, isolation Docker, secrets hors dépôt) reste dans [`docs/Reference/SECURITY.md`](docs/Reference/SECURITY.md).
